# Security policy

SwanGUI runs a privileged helper, so security reports are very welcome.

- **Do not open a public issue for vulnerabilities.** Use GitHub's private reporting:
  *Security → Report a vulnerability* in this repository.
- Please include the SwanGUI version, your distribution and the steps to reproduce.
- You will get an answer within a few days; fixes are released as soon as possible and credited unless you prefer otherwise.

Supported versions: the latest release.
